# Welcome to My Portfolio! 🚀

This is an interactive **Developer Dashboard** mimicking a modern code editor environment. Here, you can explore my professional background, skills, certifications, and contact information.

## 📁 Workspace Structure
You can navigate the files using the **File Explorer** sidebar on the left:
* `about_me.md` - A brief introduction, my core strengths, and personal summary.
* `experience.json` - Detailed timeline of my professional roles.
* `skills.yaml` - Structured technical skill categories.
* `certifications.json` - Professional certifications (AWS, Oracle) with credential links.
* `contact.sh` - Standard contacts and social networking links.

## 🛠️ Dashboard Interactive Controls
* **Theme Switching**: You can change the editor's visual palette (e.g., Tokyo Night, Dracula, Nord, GitHub Dark, One Dark) using the theme selector in the bottom status bar, or via the terminal.
* **Dual View Mode**: On any file tab, toggle the **"UI View / Code View"** button in the top right to switch between a visual graphic representation (like a career timeline or skill badges) and the raw formatting code.
* **Interactive Terminal**: Click and focus on the terminal panel at the bottom to execute commands or see help.

---

*Tip: Type `help` in the terminal panel at the bottom to get started with commands!*
